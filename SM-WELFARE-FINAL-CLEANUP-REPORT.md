## 7. Navbar Improvements

The template's own header logo has a **white wordmark** (verified by extracting and pixel-analyzing the logo embedded in the template PDFs), which is only readable on a dark header — this is why the template header is blue. The client header previously alternated white/transparent, which would have made the new logo's wordmark invisible on inner pages.

- **Header is now primary-blue on every page** (`bg-hero-gradient`, `border-b border-white/10`, sticky `z-40`), matching the template and flowing seamlessly into the home hero and sub-page heroes.
- Old transparent-overlay + scroll-to-solid logic (useState/useEffect) removed — the header is declarative and always readable.
- Nav is always the white "light" variant on the blue bar; the Donate CTA is the template's amber pill on every page.
- Logo sized/sharpened via `next/image`, clickable to `/`, `aria-label` preserved, focus ring white for contrast.
- No stretching/distortion (intrinsic ratio preserved), consistent `h-16` header height.
